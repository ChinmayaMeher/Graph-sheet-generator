# Sambalpuri Design Studio

A **web-based design studio application** for creating beautiful and intricate Sambalpuri saree, stall, border, and motif patterns.

## Features
- Interactive graph-sheet like canvas for designing.
- Customizable templates for Saree, Stall, Border, and Motif.
- Adjustable border types, color palettes, and zones.
- Advanced drawing tools including symmetry and pattern fills.
- Export functionality for finished designs.

## Tech Stack
- HTML5
- CSS3 (Vanilla / Custom Properties)
- Vanilla JavaScript

## Usage
Open `index.html` in your web browser to start using the design studio. No build process required.
